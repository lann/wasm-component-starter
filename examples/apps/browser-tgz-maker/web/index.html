Streaming tar.gz in a WebAssembly component

Pick one or more files. Their bytes are streamed into a Rust WebAssembly component that emits a tar archive, piped through the browser's own CompressionStream('gzip'), routed back through the component, and written out as archive.tar.gz — all streaming, so files larger than memory never need to be fully buffered.

Loading component…

The component exports one async function over component-model streams, archive(entries: stream<entry>) where each entry carries its own contents: stream<u8>, and imports an async streaming compressor.compress(stream<u8>). gzip happens in the host via CompressionStream('gzip'), because a component cannot call the Web CompressionStream API itself.
